# 4. 文档上传

## 4.1 功能描述
系统支持批量文件选择和并发上传，前端计算文件MD5哈希并本地去重，后端提供重复性校验接口和单文件上传API。

## 4.2 界面元素

**表 5 界面元素基本信息**

| 属性 | 值 |
| :--- | :--- |
| 界面名称 | 上传文档 |
| 界面类型 | 输入表单 |
| 展现方式 | 弹出框 |
| 上级界面 | 文档列表 |

**表 6 上传文档表单**

| 字段名 | 输入方式 | 存在性(M/C) | 必填(M/O) | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 文件选择 | fileUpload | M | M | 多文件选择+拖拽上传，支持文件夹，仅PDF/Word格式，accept=".pdf,.docx,.doc" |

**表 7 输入表单的组件**

| 组件名 | 组件风格 | 备注 |
| :--- | :--- | :--- |
| 上传按钮 | Element Plus el-button | 确认上传后触发文件校验和上传流程 |
| 取消按钮 | Element Plus el-button | 关闭对话框 |

## 4.3 处理流程

1) 前端接收用户选择的文件列表，按全路径文件名升序排列
2) 前端批量计算每个文件的MD5哈希值，对相同哈希的文件进行本地去重
3) 后台接收重复性校验请求，校验每个文件的hash格式为32位十六进制、文件名不重复
4) 后台逐条查询document表中file_hash是否已存在，返回重复文件列表
5) 后台对不与后台重复的文件逐个上传
6) 后台读取文件内容并计算MD5哈希，验证前端提供的哈希与计算值一致
7) 后台验证文件格式（PDF/Word）和大小（<=100MB）
8) 后台将文件保存到MinIO存储（以MD5哈希为文件名）
9) 后台在PostgreSQL创建文档记录（enabled=true）
10) 后台创建处理历史记录（attempt_no=1，状态=pending）
11) 后台提交数据库事务，失败则回滚并尝试清理MinIO中的孤立文件
12) 后台异步触发文档处理任务

## 4.5 异常提示

**表 8 异常提示**

| 判断条件 | 提示信息 |
| :--- | :--- |
| 选择文件为空 | 请选择文件 |
| 文件格式不是PDF/Word | 仅支持PDF、Word（.docx/.doc）格式 |
| 文件大小超过100MB | 文件大小不能超过100MB |
| 文件名长度超过255字符 | 文件名长度不能超过255个字符 |
| 前端MD5哈希与后端计算不一致 | 上传文件不完整 |
| 文件哈希与后台已有文件重复 | 与已上传文件"xxx"重复 |
| 多个文件哈希相同 | 与"xxx"文件重复 |
| MinIO存储失败 | 文件存储失败 |
| 数据库保存失败 | 文档保存失败 |

## 4.6 特殊需求
- 数据库保存失败时，系统自动尝试回滚删除已保存到MinIO的孤立文件

# 6. 文档启用

# 8. 文档处理

## 8.1 功能描述
系统对已有文档重新触发处理流程（解析→清洗→分块→入库），是对文档处理流程的容错封装。

## 8.2 前置条件
- 文档存在
- 该文档关联的版本中不存在processing状态的处理记录

## 8.3 处理流程
1) 后台查询文档是否存在
2) 后台查询该文档关联版本中是否存在processing状态的处理记录
3) 后台创建新的处理历史记录（状态=pending）
4) 后台异步触发文档处理任务

## 8.4 异常提示

**表 16 异常提示**

| 判断条件 | 提示信息 |
| :--- | :--- |
| 文档不存在 | 文档不存在 |
| 存在processing状态的关联记录 | 文档正在处理中，请稍后再试 |

## 8.5 特殊需求
无

# 10. 处理过程

# 11. 其他需求

## 11.1 文档处理

文档上传成功后，系统自动触发异步处理任务（解析→清洗→分块→入库）。文档启用/停用状态影响其是否参与知识库版本重建。文档处理功能是对文档处理流程的容错封装，触发后重新执行完整流水线。

# 数据查询

## 检索调试

### 功能描述

提供可视化调试界面，技术人员可指定知识库版本，查看混合多路检索的完整中间结果。供在版本正式启用前验证检索效果。

### 界面元素

**表 5 界面元素基本信息**

| 属性 | 值 |
| :--- | :--- |
| 界面名称 | 检索调试 |
| 界面类型 | 数据查询 |
| 展现方式 | 页面 |
| 界面地址 | /retrieval/debug |

**表 6 检索调试的搜索栏**

| 字段名 | 输入方式 | 查询方式(P/EP/BP/AP) | 备注 |
| :--- | :--- | :--- | :--- |
| 查询内容 | text | — | 输入检索问题或关键词 |
| 知识库版本 | singleSelect | P | 可选版本列表。默认值：构建成功的版本；若无，则为已启用版本；若仍无，则为最新版本 |

**表 7 检索调试的工具栏**

| 字段名 | 批量/单条(B/S/N) | 类型(P/PP/SR/SNR/C/V) | 功能 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 查询 | N | — | 执行检索 | 点击后三路并发召回 |

**表 8 检索调试的查询结果展现**

- 排序规则：按相关性分数降序

查询结果以多 Tab 形式展示，共 5 个 Tab：

| Tab 名称 | 内容 |
| :--- | :--- |
| ES 检索结果 | Elasticsearch 全文检索的原始命中列表 |
| Milvus 检索结果 | Milvus 语义检索的原始命中列表 |
| Neo4j 检索结果 | Neo4j 图谱检索的原始命中列表 |
| 合并后结果 | 三路召回经合并策略去重排序后的结果 |
| 重排序后结果 | 合并结果经重排序后的最终结果 |

每个 Tab 内的结果列表展示以下字段：

| 字段名 | 最大长度 | 选中栏展示(Y/N) | 备注 |
| :--- | :--- | :--- | :--- |
| 分块文本 | — | N | 检索匹配的分块内容 |
| 所属文档 | — | N | 分块来源的文档名称 |
| 所在页码 | — | N | 分块在文档中的页码 |
| 所在章节 | — | N | 分块在文档中的章节标题 |
| 相关性分数 | — | N | 检索结果的相关性评分 |

### 前置条件

- 所选知识库版本已构建完成，存在可检索的数据

### 处理流程

1) 前端在搜索栏展示查询文本框和版本下拉框，版本下拉框默认选中优先版本（构建成功 > 已启用 > 最新）
2) 用户输入查询内容、选择版本，点击"查询"按钮
3) 前端将查询内容和版本提交至后台
4) 后台对 Elasticsearch、Milvus、Neo4j 三路并发召回，经合并去重、补全信息、重排序后返回各阶段结果
5) 前端在 5 个 Tab 中分别展示各阶段结果，每个结果条目包含分块文本、所属文档、所在页码、所在章节

### 特殊需求

- 页面布局不受标准模板约束，采用顶部输入栏 + 下方多 Tab 数据区
- 检索返回条数可由调用方通过参数指定，各级增幅比例可配置

# 无页面需求

## 检索 API

### 功能描述

通过 HTTP API 提供知识库检索能力，供外部系统调用。基于已启用版本执行混合多路召回，返回匹配的分块文本。

### 前置条件

- 知识库存在已启用版本
- 已启用版本中存在可检索的数据

### 处理流程

1) 后台接收查询文本
2) 后台对 Elasticsearch、Milvus、Neo4j 三路并发召回，经合并去重、补全信息、重排序后截取最终结果
3) 后台返回分块文本列表

### 特殊需求

- 检索返回条数可由调用方通过参数指定
- 合并策略、重排序策略、各级增幅比例均可配置

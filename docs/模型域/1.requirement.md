## 文档解析

### 功能描述

将 PDF/Word 文档解析为结构化内容（文本、表格、图片），通过 Higress AI 网关暴露为模型调用端点。构建域文档处理流水线在解析阶段调用此端点，与在线解析服务可相互替换。

### 前置条件

- 文档文件已存在于 MinIO 中
- 文件格式为 PDF 或 Word（.docx / .doc）

### 处理流程

1) 后台通过 Higress 发送文件内容
2) 后台根据文件格式路由到对应解析器（PDF：pdfplumber；Word：python-docx）
3) 后台返回 ParseResult（章节段落、纯文本、图片元数据、表格数据）

### 异常提示

| 判断条件 | 提示信息 |
| :--- | :--- |
| 文件格式不是 PDF 或 Word | 不支持的文档格式 |
| 文件内容为空或不可读 | 文档文件不可读 |
| 解析器抛出异常 | 文档解析失败 |

### 特殊需求

无

## 向量化

### 功能描述

将文本转换为向量嵌入，通过 Higress AI 网关暴露为模型调用端点。构建域文档处理流水线在分块入库阶段调用此端点，与在线嵌入服务可相互替换。

### 前置条件

- 嵌入模型已加载至内存（首次请求时懒加载）

### 处理流程

1) 后台通过 Higress 发送待向量化的文本
2) 后台调用 sentence-transformers 推理生成向量嵌入
3) 后台返回向量嵌入（浮点数组）

### 异常提示

| 判断条件 | 提示信息 |
| :--- | :--- |
| 输入文本为空 | 向量化输入不能为空 |
| 模型加载失败 | 嵌入模型不可用 |
| 推理过程抛出异常 | 向量化失败 |

### 特殊需求

- 模型首次请求时懒加载，首请求耗时较长
- 模型加载后常驻内存，后续请求直接调用

# 其他需求

## 构建域-文档处理

解析阶段由直接调用本地库（pdfplumber / python-docx）改为通过 Higress 调用模型域 `/model/parsing` 端点。嵌入阶段由直接调用本地库（sentence-transformers）改为通过 Higress 调用模型域 `/model/embedding` 端点。

## 业务资源域-文档管理

文档上传触发的异步处理流程中，解析和嵌入调用路径同步变更。

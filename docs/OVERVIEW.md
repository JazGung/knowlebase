## 1. 业务资源域

管理企业文档和知识库版本的完整生命周期。

### 1.1 文档管理

#### 1.1.1 文档列表
分页查询文档列表，支持按启用状态过滤及关键字搜索。默认按创建时间降序排列。

#### 1.1.2 文档上传
支持批量文件选择和并发上传，前端计算文件MD5哈希并本地去重，后端提供重复性校验接口和单文件上传API。文件格式验证（仅允许PDF、Word），单文件最大100MB。上传文件保存到MinIO对象存储，数据库创建元数据记录并调用构建域触发异步处理。

#### 1.1.3 文档启用
将文档的启用状态切换为已启用。已启用文档可参与版本构建，启用后同步将知识库中该文档数据的 enabled 元数据字段设为 true。

#### 1.1.4 文档停用
将文档的启用状态切换为已禁用。已禁用文档不参与版本构建，停用后同步将知识库中该文档数据的 enabled 元数据字段设为 false，不删除数据。

### 1.2 知识库版本管理

管理知识库版本的创建、构建与启用。系统始终保持有且仅有一个启用版本。

#### 1.2.1 版本列表
分页查询版本列表，支持按状态过滤，按版本名称降序排列。

#### 1.2.2 版本新建
创建新版本记录，状态初始化为 初始化。

#### 1.2.3 版本构建
手动触发知识库构建，遍历当前所有已启用文档，调用构建域执行完整处理流水线。仅可对 初始化 或 失败 状态的版本发起构建，构建期间阻塞文档的上传/启用/停用/处理操作。

#### 1.2.4 版本启用
启用指定版本，自动替换当前启用版本（将原启用版本改为 已禁用，目标版本改为 已启用）。仅可启用 成功 或 已禁用 状态的版本。

### 1.3 文档-版本关联查询

查询文档与版本之间的关联关系列表，作为查看文档处理进度和处理记录的入口视图。按文档或版本维度过滤，按创建时间降序排列。

## 2. 构建域

执行文档处理流水线，管理处理记录与进度查询。作为业务资源域与知识库数据之间的处理层。

### 2.1 文档处理

触发文档的完整处理流水线（检查→解析→清洗→图片描述→分块→数据入库）。由业务资源域（文档工具栏"处理"按钮、文档上传完成）和版本构建流程调用。支持重新处理已有文档。

### 2.2 处理记录查询

查询指定文档-版本关联记录的处理历史，支持按处理次数降序分页，展示处理状态、开始时间、完成时间和错误信息。

### 2.3 处理详情查询

查询指定处理记录的各阶段详情（检查→解析→清洗→图片描述→分块→入库），展示运行状态、耗时和中间结果。支持 SSE 实时进度推送。

## 3. 检索域

提供知识库检索能力，支持多路召回与结果融合重排序。

### 3.1 检索 API

基于已启用的知识库版本，通过混合多路召回（Elasticsearch 全文检索、Milvus 语义检索、Neo4j 图谱检索）返回匹配的分块文本。供外部系统通过 HTTP API 调用，URL 路径为 `/retrieval`。

### 3.2 检索调试

提供可视化调试界面，URL 路径为 `/retrieval/debug`。可指定知识库版本（默认优先：构建成功版本 > 已启用版本 > 最新版本），展示各检索路径的中间结果，包含三库原始结果、合并后结果、重排序后结果，每条结果含分块文本、所属文档、所在页码、所在章节。

## 4. 模型域

封装本地模型实现，暴露标准端点供 Higress AI 网关路由。在线与本地模型对调用方透明。

### 4.1 文档解析

将 PDF/Word 文档解析为结构化内容（文本、表格、图片），封装 pdfplumber / python-docx。

### 4.2 向量化

将文本转换为向量嵌入，封装 sentence-transformers 本地推理。
